# kanpai-robot 🍻

人と AI が乾杯をするためのロボット。

AI は話し相手にはなれても、グラスを合わせることはできません。このプロジェクトは、AI に「グラスを持つ腕」を与え、同じテーブルで **声を掛け合い、タイミングを合わせ、グラスをカチンと鳴らす** ところまでを実現します。

## 目指す体験

1. 人がテーブルに着くと、ロボット(AI)が声をかけて会話が始まる
2. 人がグラスを持ち上げる、または「乾杯しよう」と言う
3. AI が音頭に応じ、「乾杯!」の声に合わせてグラスを差し出す
4. 人のグラスの位置を見て、そっと合わせる(カチン)
5. グラスを引いて、ひとこと。会話に戻る

## AI の 4 つの役割

| 役割 | 内容 |
| --- | --- |
| 音声で会話する | 人と話し、乾杯の音頭や掛け声を交わす |
| グラスを認識して合わせる | カメラで相手のグラス位置を捉え、アームで当てに行く |
| タイミングを読む | 「乾杯!」の声や動きを検知して同時にグラスを上げる |
| 遠隔の AI の身体になる | クラウド上の AI の代理として、その場でグラスを持つ |
