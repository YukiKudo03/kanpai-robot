# A1 Sayette et al. 2012 アルコールと偽薬(酒を飲まない乾杯にどこまで絆効果を期待できるか)

担当名: alcohol_ritual / 調査日: 2026-11-19

## 結論

- **偽薬群はノンアルコール統制群を上回らなかった。期待だけの効果は、この研究では検出されていない。** 行動指標(ドゥシェンヌ笑顔、発話量、3 人同時の笑顔、3 人の順番発話)はすべて、偽薬と統制の対比が有意でなかった〔本文確認: PMC 著者原稿 Results、Table 2・Table 3〕。
- **自己報告の絆は、アルコール群と統制群の差が有意でなかった**(アルコール 7.22、統制 7.07、p = .27)。アルコール群が有意に高かったのは偽薬群(6.74)との比較だけで、しかも偽薬群は統制群より低かった(p < .05)〔本文確認: Results「Self-reported social bonding」と Table 2〕。一次調査の「アルコール群は偽薬群と統制群の両方より…自己報告の絆も高かった」は、自己報告については正しくない(訂正候補 1)。
- 行動指標でのアルコール効果は大きい。事象率比は、個人のドゥシェンヌ笑顔 2.28、発話 1.25、3 人同時のドゥシェンヌ笑顔 1.81、3 人の順番発話 1.48(アルコール対 偽薬+統制)〔本文確認: Table 2・3〕。
- **統制群もノンアルコール飲料を 36 分間、同じ卓で一緒に飲んでいる。「何も飲まない」条件はない。** したがって、ノンアルコールの共飲そのものの絆効果は、この研究では測れていない。また乾杯の所作は条件に含まれない〔本文確認: Method〕。
- 設計への答え: アルコールの薬理作用がなければ、この研究が測った笑顔・発話・絆の増加は生じなかった。飲まない乾杯に酒由来の効果は期待できない。一方、「ノンアルコールで乾杯する」ことの効果は、この研究からは肯定も否定もできない〔推論〕。

### 書誌と取得元

- Sayette MA, Creswell KG, Dimoff JD, Fairbairn CE, Cohn JF, Heckman BW, Kirchner TR, Levine JM, Moreland RL. Alcohol and group formation: a multimodal investigation of the effects of alcohol on emotion and social bonding. *Psychological Science* 2012. doi:10.1177/0956797611435134。PMID 22760882、PMCID PMC5462438(Europe PMC の検索 API で DOI から確認)。
- 本文: `https://pmc.ncbi.nlm.nih.gov/articles/PMC5462438/`(著者原稿 NIHMS861768。curl で取得。**出版社版ではなく著者原稿**。Abstract、Method、Results、Table 1〜3、Discussion、Funding を読んだ)。
- 補助資料(Supplemental Material、PDF 93.6 KB)は未読。コーディングの追加詳細と手順はそちらにある〔本文未読〕。

### 標本と手順〔本文確認: Method〕

- 対象: 社会的飲酒者 720 名(男 360、女 360)、21〜28 歳、新聞広告で募集。83% が欧州系米国人。飲酒頻度は週 2〜3 回、1 回平均 4.29 杯(SD 1.89)。報酬 60 ドル。
- 3 人組(互いに初対面)にランダムに割り当て。性別構成 4 通り(男 0・女 3、男 1・女 2、男 2・女 1、男 3・女 0)を各飲料条件に 20 組ずつ。したがって 20 組 × 4 × 3 条件 = 240 組、1 条件 240 名(算術。df が t(237)、t(236) であることと整合する)〔推論〕。技術的理由で 1 名を除外。
- 飲料(等量): アルコール = ウォッカ 1 : クランベリージュース 3.5。用量は男性 0.82 g/kg、女性 0.74 g/kg。偽薬 = ウォッカ瓶に気の抜けたトニックウォーターを入れ、グラスにウォッカを塗って信憑性を高めた。統制 = クランベリージュースのみで「アルコールは出ない」と告知。
- 飲み方: 円卓に等間隔で着席。**36 分間に、飲み物の 3 分の 1 ずつを 12 分ごとに受け取る**。酔いについて話さないよう依頼。カメラは見える位置にあり、「飲酒ペースの監視のため」と説明。
- 偽薬群には飲酒後の呼気 BAC として偽の値 0.041〜0.043%(40 分後は 0.037〜0.039%)を提示した。
- 課題: 課題らしい課題はなく、初対面 3 人が飲みながら自由に交流する場面を録画し、顔(FACS)と発話を符号化。解析対象は飲み始め 3 分間を共変量(ベースライン)とし、主に 13〜36 分(2 回目・3 回目の分)。符号化したフレームは約 3,490 万。符号化者は条件に盲検。
- 一次調査の「0.82 g/kg 男性・0.74 g/kg 女性、36 分間で 3 杯」のうち、用量は一致。「3 杯」は誤り。本文の「3 杯」は参加資格(30 分に 3 杯飲めること)の記述で、飲料は 1 杯分を 3 回に分けて提供した(訂正候補 2)。

### 操作確認〔本文確認: Table 1〕

- 飲酒直後の BAC: アルコール 0.055(SD 0.012)、偽薬 0.001、統制 0.001。40 分後のアルコール群 0.062(SD 0.011)。
- 主観的酩酊(0〜100): アルコール 38.50、偽薬 14.90、統制 0.20。偽薬群は統制群より酔ったと報告したので、偽薬操作は成功している。

### 確認点ごとの答え

1. **偽薬群 対 統制群(期待のみの効果)** 〔本文確認: Table 2・3、Results〕
   - 個人レベル(事象率比、偽薬 対 統制): ドゥシェンヌ笑顔 0.86(t = −1.68、n.s.、本文では p = .07 で偽薬がやや低い傾向)、発話 0.93(t = −1.70、n.s.)、スマイルコントロール 0.97、AU9 0.95、AU14/15 1.06、複合ネガティブ指標 1.07(いずれも n.s.)。
   - 集団レベル: 3 人同時のドゥシェンヌ笑顔 0.89(t = −1.03、n.s.)、3 人の順番発話 1.04(t = 0.43、n.s.)。
   - 自己報告の絆(PGRS)だけ、偽薬 対 統制が有意(β = −0.33、t = −2.33、p < .05)で、**偽薬が統制より低い**。
   - 論文の結論: 偽薬群と統制群は似た反応を示し、アルコール群と異なった。薬理作用が用量セット(飲んでいると信じること)を上回る〔本文確認: Discussion〕。
2. **アルコール 対 偽薬+統制(効果量)** 〔本文確認: Table 2・3〕
   - 個人: ドゥシェンヌ笑顔 β = 0.82、t(237) = 8.35、事象率比 2.28。発話 事象率比 1.25(t = 5.96)。複合ネガティブ指標 事象率比 0.62(t = −4.95)。スマイルコントロール 0.54、AU9 0.61、AU14/15 0.59。AU20 は有意でない(1.36)。
   - 自己報告の絆(PGRS)β = 0.42、t = 2.75、p < .01。ただし上記のとおり、内訳は対偽薬のみ有意。
   - 集団: 3 人同時のドゥシェンヌ笑顔 事象率比 1.81(t(236) = 4.87)、3 人の順番発話 事象率比 1.48(t = 3.72)。
   - 論文は「個別に比較しても p < .01 で有意」と書く(ただし例外を明示する「別段の記載がない限り」付き)。例外が PGRS の対統制である(p = .27)〔本文確認: Analyses 節、Results〕。
   - 標準化効果量(d、r)は報告されていない。「事象率比」は、ある行動の継続時間が一方の群で他方の群の何倍かを表す〔本文確認: Table 注〕。
   - 相関: PGRS と 3 人同時のドゥシェンヌ笑顔 r = .20(p = .002)、PGRS と 3 人の順番発話 r = .21(p = .001)〔本文確認〕。
3. **用量** 男性 0.82 g/kg、女性 0.74 g/kg、中等量。飲酒直後の平均 BAC 0.055%、40 分後 0.062%(上昇期にあった)〔本文確認〕。
4. **標本と課題** 上記のとおり 720 名、240 組、初対面 3 人組の自由交流〔本文確認〕。
5. **性別の扱い** 女性は男性より笑顔・自己報告の絆とも多いが、飲料条件との交互作用は個人レベルの全指標で有意でなかった。女性が 1 人増えるごとに 3 人の順番発話 22% 増、PGRS 0.21 点増〔本文確認〕。同じデータの追加解析(Fairbairn et al. 2015、下記)では、笑顔の「伝染」へのアルコール効果は全員男性の組でのみ有意。
6. **資金源・利益相反** NIH 助成 R01 AA015773(Sayette)。「利益相反はない」と著者が宣言。酒類業界の資金は記載がない〔本文確認: Funding、Declaration〕。

### 同一データの追加解析(参考)

- Fairbairn CE, Sayette MA, Aalen OO, Frigessi A. *Clin Psychol Sci* 2015(2014 年オンライン、3(5):686–701、doi:10.1177/2167702614548892)。PMC 著者原稿 PMC4615679 で冒頭・方法・結果の一部を確認〔本文確認: 部分読み〕。偽薬と統制を併合する前に両者の対比が有意でないことを確認している。笑顔が相互の笑顔に発展する確率は、アルコール 49.6%、偽薬 45.6%、統制 44.6%で、偽薬と統制は差がなかった。アルコールが相互の笑顔への移行を速める効果(21% 増)は全員男性の組でのみ有意(p = .025)で、女性を含む組では有意でなかった。

### 論点の補足

- 統制群の飲み物は、同じ卓で同じ速度で、全員が同じクランベリージュースを飲む。つまり比較の基準線に「共同でノンアルコール飲料を飲む」ことが含まれる〔本文確認〕。したがって、アルコールの追加効果は測れるが、ノンアルコール飲料の共飲が「何もしない」場合より絆を高めるかは測れない〔推論〕。
- 3 人組の初対面・自由交流の場面での結果であり、乾杯の所作・掛け声・視線合わせといった形式の操作は含まれない。乾杯を扱った研究として読んではならない〔推論〕。
- 反証・留保: 参加者は 21〜28 歳の米国の社会的飲酒者(欧州系 83%)で、日本人・年配者・知人同士には一般化できない。自己報告の絆は 12 項目の尺度で、本文は 1 = 強く同意〜9 = 強く不同意と記すが、結果は「高いほど絆が強い」と解釈している(逆転処理がされたと推測される〔推論〕。補足資料で要確認)。
- 追試・批判: この論文の直接の追試は検索で見つからなかった(WebSearch「Sayette 2012 group formation alcohol placebo replication critique」)。関連して Bowdring & Sayette 2018 は、集団内で偽薬反応が他の 2 人から独立していたことを報告したと検索要約にあるが、本文未読〔二次情報〕。

## 設計に使える数値

作業指示書 4 節 C の数値項目(接触速度、視線の長さ等)に該当するものは**なし**。参考として、乾杯という共同行為ではなく飲酒中の初対面交流についての指標を記す。

- 事象率比(アルコール 対 偽薬+統制、初対面 3 人組 240 組、36 分の飲酒): 個人のドゥシェンヌ笑顔 2.28、発話 1.25、3 人同時のドゥシェンヌ笑顔 1.81、3 人の順番発話 1.48〔本文確認: Table 2・3〕。ノンアルコール条件ではこの増加がない、という否定的な基準線として使える。
- 偽薬の効果の上限: 偽薬は主観的酩酊を 14.9(統制 0.2)に上げても、行動指標は変えなかった〔本文確認: Table 1・2〕。

## 設計への含意(〔推論〕)

- `docs/concept.md` の「ロボットは飲まない(当面)」と `docs/safety.md` の「乾杯の相手はお茶でも水でもよい」について: 酒由来の絆効果(笑顔の同期、発話の増加)は、飲まない乾杯の効果見積もりから**除外すべき**。偽薬(飲んでいると信じること)だけでは何も起きなかったので、ロボット側が「飲むふり」をして人に酒を期待させても効果は見込めない。これは「飲むふりをしない」方針の補強材料にはなるが、方針の決定そのものは依頼者の判断事項。
- 逆に、ノンアルコールの共飲を比較の基準線にした実験デザインは参考になる。評価実験(`docs/roadmap.md`)では、「乾杯なしで同じ飲み物を飲む」「乾杯して飲む」「乾杯だけして飲まない」を分ければ、この研究が測れなかった形式の効果を測れる。
- 酒を飲む人間側には薬理効果が生じうる(ロボットとは共有できない)。この研究は、相手も酔っていることが必要かを分離していない。
