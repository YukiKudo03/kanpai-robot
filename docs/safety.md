# 安全設計

食卓で、人の手とガラスと液体のすぐそばで動くロボットです。安全は機能の一部として最初から設計に含めます。

## 想定するリスクと対策

| リスク | 対策 |
| --- | --- |
| グラスが割れる | 接触時の速度を低く制限する。最終接触は人に委ねる。ロボット側は割れにくい容器から始める。手先に緩衝を入れる |
| 手や指を挟む・叩く | 低出力のサーボを使う。速度と力に上限を設ける。負荷の急増で即停止・脱力する |
| 顔に向かって動く | 動作範囲をテーブル上の低い領域に限定し、範囲外の目標は拒否する |
| 飲み物をこぼす・倒す | ロボットのグラスは空または蓋付きから始める。テーブル上の物に届かない軌道に限定する |
| 液体による電気事故 | 電子部品を防滴または高所に配置する。低電圧で駆動する |
| ソフトの暴走・通信断 | 指令が途絶えたらその場で停止する。物理的な非常停止スイッチでサーボ電源を切れるようにする |
| AI の予期しない出力 | AI は意図だけを伝え、動作は制限付きのコントローラが生成する(→ [architecture.md](architecture.md)) |

## 層になった保護

1. **機構**: 低出力のサーボ、軽い腕、緩衝付きの手先。最悪の場合でも大きな力が出ない。
2. **物理スイッチ**: ソフトを経由せずにサーボ電源を切る。
3. **安全監視モジュール**: すべての動作指令が通る関門。速度・加速度・動作範囲・負荷を検査し、違反は停止に変える。
4. **状態機械**: 決められた状態と遷移の中でしか動かない。時間切れで必ず安全な姿勢に戻る。
5. **AI との境界**: AI からは少数の意図しか受け付けない。

下の層ほど単純で、上の層が誤っても下の層が止めます。

## お酒について

- ロボットは飲酒を勧めたり、飲む量を煽ったりしない。乾杯の相手はお茶でも水でもよい。
- 酔った人が相手になることを前提に、乱暴に扱われても危険が生じない強度と挙動にする。
- 未成年が相手になりうる場での運用は、別途検討する。

## 運用の決まり(開発時)

- 新しい動作は、まずシミュレータ、次にグラスなし、最後にグラスありの順で試す
- 実機を動かすときは非常停止スイッチに手が届く位置にいる
- 速度制限は低い値から始め、検証しながら上げる
