# 安全設計

食卓で、人の手とガラスと液体のすぐそばで動くロボットです。安全は機能の一部として最初から設計に含めます。飲酒を促さないこと、機械であることを偽らないことも安全の範囲とします。根拠は [design-rationale.md](design-rationale.md) にまとめています。

## 想定するリスクと対策

| リスク | 対策 |
| --- | --- |
| グラスが割れる | 接触時の速度を低く制限する。最終接触は人に委ねる。ロボット側は樹脂のグラスから始める。手先に緩衝を入れる |
| 手や指を挟む・叩く | 低出力のサーボを使う。速度と力に上限を設ける。負荷の急増で即停止・脱力する |
| 顔に向かって動く | アームの動作範囲をテーブル上の低い領域に限定し、範囲外の目標は拒否する |
| 頭部に触れる・挟む | 頭部は低出力のサーボとし、アームと同じ安全監視の下に置く。手やグラスが届きにくい位置に置く |
| 見つめ続けて不快にさせる | 1 回の注視時間に上限を設ける(仮置き、[architecture.md](architecture.md))(根拠は [design-rationale.md](design-rationale.md)) |
| 飲み物をこぼす・倒す | ロボットのグラスは空または蓋付きから始める。テーブル上の物に届かない軌道に限定する |
| 液体による電気事故 | 電子部品を防滴または高所に配置する。低電圧で駆動する |
| ソフトの暴走・通信断 | 指令が途絶えたらその場で停止する。物理的な非常停止スイッチでサーボ電源を切れるようにする |
| AI の予期しない出力 | AI は意図だけを伝え、動作は制限付きのコントローラが生成する(→ [architecture.md](architecture.md)) |
| 飲酒を促す・過度の愛着 | 乾杯の頻度を制限し、飲酒を勧める発話をしない。飲むふりをしない(下記) |

## 層になった保護

1. **機構**: 低出力のサーボ、軽い腕と頭部、緩衝付きの手先。最悪の場合でも大きな力が出ない。
2. **物理スイッチ**: ソフトを経由せずにサーボ電源を切る。
3. **安全監視モジュール**: アームと頭部のすべての動作指令が通る関門。速度・加速度・動作範囲・負荷を検査し、違反は停止に変える。
4. **状態機械**: 決められた状態と遷移の中でしか動かない。動作中のどの状態にも時間切れと中断(人が離れた、グラスを引いた、目標が範囲外)の遷移があり、グラスを引いて安全な姿勢に戻る。戻れなければ安全停止の状態に移り、脱力する([architecture.md](architecture.md))。やり直しにも上限がある。
5. **AI との境界**: AI からは少数の意図しか受け付けない。頻度の制限はコントローラが守る。

下の層ほど単純で、上の層が誤っても下の層が止めます。

## 接触速度・力の上限

グラスを割らない接触速度・力も、人が乾杯で実際に出す接触速度も、文献に見つかりませんでした。上限値は仮置きとし、実測で決めます。

**当面の扱い(仮置き)**

- 最終接触は人が詰める。ロボットは手前で待ち、追従は控えめにする
- 人のグラスの近くでのロボットの速度と、負荷の急増で停止する閾値は、シミュレータ、グラスなし、グラスありの順に低い値から上げる
- 協働ロボットの国際技術仕様(ISO/TS 15066)の接触の上限は、手への意図しない接触の痛みの基準で、グラスを割らない値ではないので、上限の根拠にはしません

**確定の手順**

1. 人同士の乾杯で、接触時の相対速度の分布を測る(計測 1、[roadmap.md](roadmap.md))
2. 飲用ガラス・強化ガラス・樹脂の縁の衝撃試験で、割れる衝撃エネルギーと速度を測る(計測 2)
3. 両者の比から、ロボット側の速度と力の上限を決める。ロボットからも寄せに行く方式は、この後に検討する
4. 接触検知の誤検出と見逃しの率を測り(計測 5)、停止の閾値を決める

## お酒について

### 乾杯の頻度

| 規則 | 内容 | 値(仮置き) |
| --- | --- | --- |
| ロボットから誘う | 会話の節目に限る。1 回の利用での回数に上限を設ける | 上限回数は M2([roadmap.md](roadmap.md))で初期値を決め、利用のログで見直す |
| 人から誘われた | 断らずに応じる。前回から短い間隔で続くときは「ゆっくりいきましょう」と声をかける | 間隔 2.5 分(先行機である KAIST の飲酒相手ロボットの値。[design-rationale.md](design-rationale.md)) |
| 飲み物の種類 | お茶や水のときも当面同じ規則にする(暫定、依頼者の確認待ち) | 利用の偏りや愛着への歯止めとして(推論) |

### 発話の方針

飲酒を勧めないこと、乾杯の相手はお茶でも水でもよいことは、初版からの方針です。

- 飲酒を勧めない。「もう一杯」「飲み干して」など、飲む量を煽る言葉を言わない。
- 乾杯の後に飲むことを促さない。乾杯だけでよいことを伝える。
- 乾杯の相手はお茶でも水でもよいと伝える。ただし、酒と同じ効果があるとは言わない(根拠がない)。
- ロボット自身は飲めないことを、最初に自分から伝える。
- 飲めない人や断酒中の人がいることを前提にする。

### その他

- 酔った人が相手になることを前提に、乱暴に扱われても危険が生じない強度と挙動にする。
- 未成年が相手になりうる場での運用は、別途検討する。

## 欺瞞と過度の愛着への配慮

社会ロボットの欺瞞は害をもたらす場合に問題になり、感情があるように見せること、理解力を過大に見せることがリスクとされます(Sharkey & Sharkey 2021)。乾杯や飲酒の文脈の研究はありませんが、一人で飲む寂しい利用者は脆弱な層に当たりうるため(推論)、次の配慮を置きます。1 項目めは依頼者の方針(飲むふりをしない)によるもので、残りは暫定です(依頼者の確認待ち)。

- 機械であることを隠さない。飲むふりをしない([concept.md](concept.md))。
- 感情の演出は控えめにし、依存を強める言葉を使わない。
- 頻度の制限を、飲酒量だけでなく利用の偏りの歯止めとしても扱う。

## 運用の決まり(開発時)

- 新しい動作は、まずシミュレータ、次にグラスなし、最後にグラスありの順で試す
- 実機を動かすときは非常停止スイッチに手が届く位置にいる
- 速度制限は低い値から始め、検証しながら上げる
- 人が参加する計測実験は飲酒を伴わない条件から始める。飲酒を伴う場合は、酔いが覚めるまで帰さないなどの手当てを計画に含める
