# 設計判断と根拠

設計上の判断と、その根拠になった文献の対応表です。文献の詳細、数値の条件、読めなかった文献は [調査レポート「乾杯の文献詳細調査」](../reports/乾杯の文献詳細調査.md) にあります。この文書は 2026-11-19 時点のもので、計測実験の結果で更新します。

## 凡例

### 判断の種別

| 種別 | 意味 |
| --- | --- |
| 方針 | 依頼者が 2026-11-19 に決めた方針(調査レポート 9 節の 7 件)。文献は判断の材料で、決め手ではない |
| 既存方針 | 調査より前の初版の設計文書からある方針。調査で覆す材料は見つからなかった |
| 暫定 | 7 件の方針を設計に落とす際に設計側で暫定的に決めたもの。依頼者の確認待ち([roadmap.md](roadmap.md) の「確認待ちの暫定事項」) |
| 文献 | 〔本文確認〕の文献から直接言えることに基づく判断 |
| 仮説 | 採用するが、根拠が乾杯以外の研究からの類推か推論にとどまる判断 |
| 仮置き | 文献で値が決まらないため仮の値を置き、計測実験で確定させるもの。計測の番号は [roadmap.md](roadmap.md) を参照 |

### 確認度

調査レポートのラベルをそのまま写しています。格上げはしていません。

| ラベル | 意味 |
| --- | --- |
| 〔本文確認〕 | 論文本文を読んで確認した |
| 〔本文確認(総説経由)〕 | 総説の本文で読んだ値。元の研究は未読 |
| 〔要旨確認〕 | 要旨または著者の公式要約だけを確認した |
| 〔二次情報〕 | 他の文献、解説記事、検索結果の要約による |
| 〔未確認〕 | 確認できなかった。設計には使わない |
| 〔推論〕 | 文献からの推論 |

〔本文確認〕でも、乾杯以外の題材(受け渡し、握手、楽器など)の研究は、乾杯の値ではなく **類推** です。表では「類推」と書き添えます。

### 用語

| 用語 | 意味 |
| --- | --- |
| 先行機 | 唯一の先行例である KAIST の飲酒相手ロボット(Jung ら 2023、Kim ら 2021)。腕のない卓上の車輪ロボット |
| 主体感 | 自分が行為を起こし、その結果を動かしているという感覚。評定で尋ねるもの(明示的)と、意図的結合で測るもの(潜在的)がある |
| 意図的結合 | 自分の行為とその結果の間の時間が短く感じられる現象。主体感の潜在的な指標として使われる |
| g、d | 効果量。群の差を標準偏差で割った値で、差の大きさを表す |
