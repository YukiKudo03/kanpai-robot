# ハードウェア構成案

ハードウェアは未選定です。ここでは必要な要件と候補を整理し、推奨案を示します。価格と仕様は記憶に基づく概算で、**購入前に必ず最新の情報を確認してください**。

## 要件

| 項目 | 要件 | 理由 |
| --- | --- | --- |
| 可搬重量 | 手先で 200〜300 g 以上 | 空のグラス、または軽量のタンブラーとホルダの重さ |
| 到達距離 | 30〜40 cm | テーブル越しに人のグラスへ届く |
| 自由度 | 位置 3 + グラスを立てたまま保つ 1〜2 | グラスを傾けずに差し出す |
| 速度 | 待機位置まで 0.5〜0.8 秒(仮置き) | 掛け声に間に合わせる。値は計測で見直す([architecture.md](architecture.md) の遅延予算) |
| 力の感知 | 関節の負荷または電流が読める | 接触の検知と、ぶつかったときの停止 |
| 静音性 | 会話を妨げない | 音声認識と体験の両面 |
| 脱力 | 電源断・異常時に力が抜ける | 挟み込みを避ける |
| 頭部 | 首振り 2 軸(左右・上下)を基本、カメラ内蔵 | 人の顔の向きを捉え、相手を見る・グラスを見るといった視線を示す(下記) |

## アームの候補

| 案 | 構成 | 概算費用 | 長所 | 短所 |
| --- | --- | --- | --- | --- |
| A | 専用の 2〜3 軸機構を自作 | 1〜3 万円 | 安価で小型、乾杯に特化した見た目にできる | 機構設計が必要。位置合わせの自由度が低い |
| B | オープンソースの小型アーム(SO-101 など、シリアルバスサーボ 6 軸) | 数万円 | 位置・負荷の読み取りが可能。設計データとソフトが公開されている。脱力できる | 組み立てが必要。剛性と精度は控えめ |
| C | 市販の卓上アーム(myCobot など) | 10 万円前後〜 | 完成品で届く。サポートがある | 高価。力の感知は機種による |

### 推奨: 案 B

- 関節の位置と負荷が読めるため、接触検知と安全停止をソフトだけで実装できます。
- 乾杯の最終接触を人に委ねる設計なので、高い位置精度は不要で、控えめな剛性はむしろ当たりの柔らかさとして働きます。
- 3D プリントの部品を差し替えれば、後から乾杯専用の外装や手先に作り変えられます。
- 頭部の首振りにも同じ種類のサーボを使えば、制御と電源を共通にできます。

機構を極力シンプルにしたい、あるいは見た目を重視する場合は案 A が有力です。ソフトはハードウェア抽象層で分離するため、後からの乗り換えも可能です。

なお、唯一の先行機(KAIST の飲酒相手ロボット)は腕のない卓上の車輪ロボットで、前進して利用者のグラスに当てる方式でした。機構が違うため、腕の速度・力・軌道の数値は先行機から引き継げません。

## 頭部(ロボットの「目」)

首を振る頭部を追加し、カメラを内蔵します。相手の顔を見る、グラスを見る、目が合うのを待つ、という視線を示すためです。

- 直視を見たときの皮膚電気反応は、相手から見られていると分かることが条件で、同席は不要だったという研究があります(Hietanen ら 2020、32 名。快・覚醒の自己評定には差がなかった)。頭部のない固定カメラでは、見られている手がかりが乏しいと考えられます(推論)。
- ロボットが頭部の向きだけで受け渡し位置を見ると、人は約 0.63 秒早く手を伸ばしました(Moon ら 2014、受け渡しの研究で乾杯ではない)。
- 頭部の向きだけでは細かい視線の方向は伝わりにくいとされます。画面の目(白目と黒目の表示)は、頭部だけの構成と後から比べます。頭部だけ・画面の目・機械式の目を直接比べた研究はありません。

| 項目 | 内容 |
| --- | --- |
| 軸 | 左右・上下の 2 軸を基本とする。1 軸(左右のみ)にする場合は、グラスへ視線を向ける動作を省く |
| 速さ | 人の顔とグラスの間を素早く向き替えられること。目安の値は計測で決める |
| カメラ | 頭部に 1 台。人の顔の向き(相互注視の判定)に使う |
| 候補 | (1) アームと同じシリアルバスサーボ 2 個 + 3D プリントの首 + 小型 USB カメラ、(2) ホビー用サーボのパン・チルト台 + USB カメラ |
| 費用への影響 | 数千円〜1 万円程度の追加(概算、要確認) |
| 安全 | 低出力のサーボとし、アームと同じ安全監視の下に置く。頭部はグラスや手に触れない位置に置く |

手元とグラスの位置推定は、当面これまでどおり固定の広角カメラで行い、頭部のカメラは顔の向きに使います。頭部のカメラだけで両方を賄えるかは、M4 で確かめます。

## 手先(グラスの持ち方)

汎用のグリッパでグラスを掴むのではなく、**グラスを固定する専用ホルダ** を手先に付けます。

- 掴み損ねて落とす事故がなくなる
- ホルダにばねやゴムを入れて、接触の衝撃を逃がせる
- **有脚のガラス製グラスでは、脚または底の近くを点で柔らかく保持する**(仮説)。ワイングラスの振動の振幅は底から縁へ向けて大きくなり、底の近くはほとんど動かないという研究(Jundt ら 2006)からの推論です。当面使う樹脂のタンブラーは形も減衰も違うため、この仮説は当てはめず、把持位置は計測 3 で確かめます。持ち方と余韻の関係を測った研究はないので、どちらも吊り下げたグラスとホルダに付けたグラスを同じ打撃で鳴らし、余韻を比べて決めます

## グラスの材質と音

**当面、ロボット側のグラスは割れにくい樹脂(トライタンなど)とします。** 飲用ガラスが割れる接触速度・力は文献に見つからず、上限を決められないためです。

| 論点 | 現状 | 次の判断 |
| --- | --- | --- |
| 材質 | 樹脂で開始。グラスの縁は最も割れやすい部位とされる | 接触音の録音比較(計測 3)と縁の衝撃試験(計測 2)の後に、本物のガラスにするか、樹脂のままスピーカーで音を補うかを決める |
| 音 | 人は実際の衝撃音でガラスとアクリルを聞き分けたという研究があり(要旨確認)、樹脂の音はガラスと別物に聞こえる公算が大きい(推論)。先行機では、本物のグラスの音と感触を評価する参加者がいた | 成功の基準「グラスが合ったとき、音が鳴る」とは緊張関係にあるため、計測の結果で見直す |
| 液量 | ロボットのグラスは当面、空または蓋付きとする。液体を入れると音は低く短くなるという研究があるので、空のグラスは高く長く鳴る側に寄る(推論) | 中身の扱いは未決事項([roadmap.md](roadmap.md)) |
| スピーカーで補う場合 | 接触点の近くに小型スピーカーを置く。グラスと音源が離れると、音と自分の動きを結びつけにくかったという展示の観察がある(質的な観察)。遅延は接触から 10 ms 以内、20〜25 ms を上限の目安とし、音を接触より先に出さない(楽器の遅延の研究などからの推論で仮置き) | 計測 4 で許容遅延を確かめる。接触の検出から音を出すまでの経路を短くする必要がある |

## その他の構成部品

| 部品 | 候補 | 備考 |
| --- | --- | --- |
| コンピュータ | ノート PC(開発時)→ Raspberry Pi 5 など(組み込み時) | まず PC で開発し、処理負荷を見てから決める。顔の向きの推定が加わる |
| カメラ | 固定の USB カメラ 1 台(広角)+ 頭部のカメラ 1 台 | 深度カメラは透明物に弱く、必須ではない |
| マイク | エコーキャンセル付きの USB スピーカーフォン | 自分の声とサーボ音を拾わないことが重要。接触の衝撃音の検出にも使う |
| スピーカー | 同上 | 音を補う場合は、別に接触点近くの小型スピーカー |
| 非常停止 | サーボ電源を直接切る物理スイッチ | ソフトを経由しない。頭部のサーボも同じ系統で切る |
| 電源 | サーボ用とコンピュータ用を分離 | サーボの負荷変動でコンピュータが落ちないように |

## 設置

- アームと頭部の土台はクランプか重りでテーブルに固定する
- 固定カメラはアームの土台近くに置き、人の手元とロボットのグラスの両方を写す
- 頭部は人の顔の高さを見上げられる位置に置き、アームの動作範囲と干渉させない
- 電子部品は飲み物より高い位置か、こぼれても濡れない囲いの中に置く
