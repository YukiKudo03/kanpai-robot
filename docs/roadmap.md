# 開発ロードマップ

各段階は「人が体験できるもの」を区切りにしています。ハードウェアの調達と並行して、ソフトはシミュレーションで先行します。文献で決まらなかった値は、主に M3〜M5 の計測実験で決めます。

## マイルストーン

| 段階 | 名前 | できるようになること | 実機 |
| --- | --- | --- | --- |
| M0 | 設計 | コンセプト、構成、ハード候補の整理(本ドキュメント群) | 不要 |
| M1 | シミュレーションで乾杯 | 仮想アーム・仮想頭部と仮想の人で、状態機械が一連の乾杯(注視の待ち、接触の判定とやり直しを含む)を完走する。画面上で動きを確認できる | 不要 |
| M2 | 声で乾杯 | マイクに「乾杯!」と言うと、シミュレータのアームが反応する。AI と会話でき、会話の節目に乾杯に誘われる。PC のカメラで目が合うのを待ってから「乾杯!」と言う | PC のマイク・スピーカー・カメラ |
| M3 | 決まった位置で乾杯 | 実機のアームが掛け声に合わせて決まった位置にグラスを差し出し、人が当てる。接触を判定して引き、合わなければやり直す | アーム |
| M4 | 見て合わせる | カメラで人のグラス(手)の位置を捉え、その手前に差し出す。人がどこに出しても合う。頭部が人の顔とグラスを見る | アーム + カメラ + 頭部 |
| M5 | 息を合わせる | 声と動きと視線からタイミングを読み、人と同時に動き出す。空振りからやり直せる | 同上 |
| M6 | 乾杯相手としての完成 | 身振り、個性、外装。初めての人が説明なしで乾杯できる | 同上 |

## 直近の作業(M1)

1. Python プロジェクトの雛形(パッケージ構成、テスト、静的検査)
2. ハードウェア抽象層のインターフェースと、仮想アーム・仮想頭部
3. 乾杯の状態機械と単体テスト(注視の待ち、時間切れと中断、接触の判定とやり直し、安全停止、頻度の管理)
4. 安全監視モジュール(アームと頭部の速度・範囲の制限)
5. 仮想の人(グラス位置、顔の向き、掛け声。目が合わない、空振り、途中で離れる、連続した乾杯を含む)
6. 仮置きの値を集めた設定ファイルと、動きを確認できる簡易な可視化

M1 と並行して、ハードウェア(アームと頭部)の最終選定と発注を進めます。

## 計測実験(主に M3〜M5)

乾杯での値が文献にない項目を測ります。番号は [調査レポート](../reports/乾杯の文献詳細調査.md) 10 節の案と同じで、15 は依頼者の判断を受けて追加しました。計測 14 は長期利用が前提なので M6 に置きます。方法は実験計画の段階で詰めます。

| 時期 | # | 計測 | 決める値 |
| --- | --- | --- | --- |
| M3(実機不要、早めに行ってよい) | 1 | 人同士の乾杯(掛け声から接触までの時間、到達のずれ、接触時の相対速度、視線) | 遅延予算、軌道、速度の上限 |
| M3 | 2 | グラスの縁の衝撃試験(ガラス、強化ガラス、樹脂) | 速度・力の上限、材質 |
| M3 | 3 | 接触音の録音比較(材質、液量、ホルダの位置) | 材質、把持位置 |
| M3 | 5 | 接触検知の誤検出と見逃しの率 | 成否の判定規則、停止の閾値 |
| M3 | 15 | 押し返しの強さ(受け止めるだけ / 弱く押し返す) | 押し返しの既定 |
| M4 | 4 | スピーカー補音の許容遅延(補う案を採る場合) | 補音の遅延 |
| M4 | 7 | 接近速度と不快・自然さ | 接近速度 |
| M4〜M5 | 9 | 不快にならない注視の長さ(日本人) | 1 回の注視時間 |
| M5 | 6 | 動き出しの遅延と待たされ感 | 遅延予算 |
| M5 | 8 | 追従の強さ(補正なし・小・大) | 追従の強さ |
| M5 | 10 | 発声前の相互注視を待つ / 待たないを操作し、グラスを上げる・声を返す・自己評定を比べる。待ちの上限と待たされ感も併せて測る | 待ちの上限 |
| M5 | 12 | 空振りとやり直しの振る舞い | やり直しの上限と発話 |
| M6 | 14 | 乾杯の間隔と「ゆっくり」への反応(利用ログ) | 頻度の規則 |
| 画面の目を検討する段階 | 11 | 頭部だけと画面の目を加えた場合の比較 | 目の構成 |
| 計画のみ | 13 | 乾杯の要素の効果の統制実験(下記) | — |

計測 13 は、乾杯の要素(視線・音・接触・唱和)や口元へ運ぶ身振りの有無で親しみを比べる統制実験です。人数と倫理審査の負担が大きいため計画の記載にとどめます。行う場合は、実験者の盲検化、事前登録、小さな効果を前提にした標本数(効果量 0.2〜0.3 程度での試算で 1 群 160〜390 名程度)を条件とします。

## 決定済みの事項

2026-11-19 に依頼者が判断しました(根拠は [design-rationale.md](design-rationale.md))。

| 項目 | 決定 |
| --- | --- |
| 飲む動作 | しない。飲めないことを自分から伝える。口元へ運ぶ身振りは将来の比較条件 |
| グラスの材質 | 当面は樹脂。計測 2・3 の後にガラスかスピーカー補音かを決める |
| 目・頭部 | 首振りの頭部(2 軸が基本、カメラ内蔵)。画面の目は後から比較 |
| 相互注視 | 緩い条件。短時間待ち、時間切れなら発声する |
| 乾杯の頻度 | ロボットから誘うのは会話の節目だけ + 回数上限。人からは断らず「ゆっくり」と添える |
| 評価実験の扱い | 計測実験を主に M3〜M5 に入れる(計測 14 は M6)。統制実験は計画のみ |
| 最終接触と押し返し | 人が最後の数センチを詰める(安全のため)。押し返しの強さは計測 15 で決める |

## 確認待ちの暫定事項

7 件の判断を設計に落とす際に暫定的に決めたものです。依頼者の確認を受けて確定します(反映先は各文書に「暫定」と記載)。

| 項目 | 暫定の内容 |
| --- | --- |
| 人が先に「乾杯!」と言ったとき | 目が合うのを待たずに応じる |
| お茶や水のときの頻度 | 酒のときと同じ規則にする |
| 欺瞞と愛着への配慮 | 感情の演出を控える。依存を強める言葉を使わない。頻度の制限を利用の偏りの歯止めにも使う |
| 押し返しの既定 | 計測 15 までは「受け止めるだけ」 |
| やり直し | 上限 1 回。上限に達したら「また後で」と言って引く |

## 未決事項

決まり次第、該当する文書に反映します。

| 項目 | 選択肢・論点 | 影響する範囲 |
| --- | --- | --- |
| アームの選定 | 自作の専用機構 / オープンソースの小型アーム / 市販品(→ [hardware.md](hardware.md)) | 予算、M3 の開始時期 |
| 頭部の構成 | アームと同じサーボで自作 / 市販のパン・チルト台。2 軸を基本とし、1 軸にするか | 予算、M4 |
| グラスの材質の最終決定 | 本物のガラス / 樹脂のままスピーカーで補う(計測 2・3 の後) | 手先、安全、音 |
| 予算と台数 | 1 台の試作か、複数台の展示か | ハード全般 |
| 利用場面 | 自宅の食卓 / 飲食店 / イベント展示 | 騒音対策、耐久性、外装 |
| ロボットのグラスの中身 | 当面は空または蓋付き。最終的に 空 / 蓋付きで液体入り / 開いたグラス | 手先の設計、安全、音 |
| グラスを合わせない乾杯 | 目の高さに掲げるだけの乾杯を選べるモードにするか(改まった席では合わせないという作法がある) | 状態機械、体験 |
| 場面による発声の主導 | 改まった場では音頭取りに従う / くだけた場では互いに声を合わせる | 状態機械、対話 |
| ロボットからも寄せに行くか | 接触速度の上限が決まった後に検討 | 安全、体験 |
| 口元へ運ぶ身振り | 比較条件に使う場合、アームの到達・自由度と動作範囲の安全制限で対応できるか未検討 | ハード、安全 |
| 対話 AI と音声の方式 | 音声認識 + 対話 AI + 音声合成の組み合わせ / 音声対話一体型 | 応答の遅延、費用 |
| AI の人格 | 名前、話し方、乾杯の掛け声の言い回し、飲めないことの伝え方 | 対話の設計 |
| 対応言語 | 日本語のみ / 多言語(Cheers、건배 など) | 掛け声検知 |
| 複数人での乾杯 | 一対一のみ / 順番に全員と合わせる | 視覚、視線、状態機械 |
