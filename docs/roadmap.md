# 開発ロードマップ

各段階は「人が体験できるもの」を区切りにしています。ハードウェアの調達と並行して、ソフトはシミュレーションで先行します。

## マイルストーン

| 段階 | 名前 | できるようになること | 実機 |
| --- | --- | --- | --- |
| M0 | 設計 | コンセプト、構成、ハード候補の整理(本ドキュメント群) | 不要 |
| M1 | シミュレーションで乾杯 | 仮想アームと仮想の人で、状態機械が一連の乾杯を完走する。画面上で動きを確認できる | 不要 |
| M2 | 声で乾杯 | マイクに「乾杯!」と言うと、シミュレータのアームが反応する。AI と会話でき、AI から乾杯に誘われる | PC のマイクとスピーカー |
| M3 | 決まった位置で乾杯 | 実機のアームが掛け声に合わせて決まった位置にグラスを差し出し、人が当てる。接触を検知して引く | アーム |
| M4 | 見て合わせる | カメラで人のグラス(手)の位置を捉え、その手前に差し出す。人がどこに出しても合う | アーム + カメラ |
| M5 | 息を合わせる | 声と動きの両方からタイミングを読み、人と同時に動き出す。空振りからやり直せる | 同上 |
| M6 | 乾杯相手としての完成 | 身振り、個性、外装。初めての人が説明なしで乾杯できる | 同上 |

## 直近の作業(M1)

1. Python プロジェクトの雛形(パッケージ構成、テスト、静的検査)
2. ハードウェア抽象層のインターフェースと、仮想アーム
3. 乾杯の状態機械と、その単体テスト
4. 安全監視モジュール(速度・範囲の制限)
5. 仮想の人(グラスの位置と掛け声を生成するシナリオ)
6. 動きを確認できる簡易な可視化

M1 と並行して、ハードウェアの最終選定と発注を進めます。
